# Mitarbeiter-App (Flutter)

Platzhalter für die künftige Flutter-App, mit der Mitarbeiterinnen die Beratung durchführen (iPad, iPhone, Android-Tablet, Android-Smartphone, perspektivisch Web).

Kernprinzip: **One Tap. One Decision.** — eine Entscheidung pro Bildschirm, kaum Texteingabe, große Karten, automatische Weiterleitung (siehe [Projektbeschreibung.md](../docs/Projektbeschreibung.md), Abschnitt 6–8).

**Status:** noch kein Code. Wird erst nach Abschluss und Validierung des Figma-Prototyps aufgesetzt (`flutter create`), damit der Beratungsflow vorher fachlich feststeht.
