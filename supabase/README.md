# Supabase

Platzhalter für das künftige Datenbankschema, Migrations und Auth-/Storage-Konfiguration — die zentrale Datenquelle, aus der sowohl Mitarbeiter-App als auch Admin-Bereich lesen (siehe [Projektbeschreibung.md](../docs/Projektbeschreibung.md), Abschnitt 15).

Geplante Kernentitäten (aus dem Konzept abgeleitet, noch nicht final modelliert): Kundin/Beauty Case, Beratung, Ziel, Pain Point, Hautanalyse, Hautbedürfnis, Behandlung, Produkt, Programm, Regel, Kontraindikation, Beauty Blueprint.

**Status:** noch kein Schema. Wird erst nach Abschluss und Validierung des Figma-Prototyps aufgesetzt (`supabase init`).
