# Originalfotos

Unveränderte Ausgangsdateien (1800 px) der Behandlungsfotos.

Die ausgelieferten Varianten (`*-760.*`, `*-1400.*` als JPEG und WebP eine Ebene
höher) werden aus diesen Dateien erzeugt. Wenn hier ein Foto ersetzt wird — z. B.
durch ein echtes Studiofoto statt des Unsplash-Platzhalters —, müssen die
Varianten neu erzeugt werden.
